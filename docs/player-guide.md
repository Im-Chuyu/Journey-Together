# 伙伴手册

[项目首页](../README.md) · [English](en/player-guide.md)

## 安装与设置

在世界的服务器模组列表启用「一路同行」。如果使用 GitHub 源码，把解压出的模组文件夹放进游戏的 `mods/`，确认打开该文件夹就能看到 `modinfo.lua` 和 `modmain.lua`。每位玩家与服务器需要相同版本，专服的地面和洞穴分别配置。

伙伴首次生成时默认是温蒂，位置优先选择绚丽之门等世界入口。重进已有世界会恢复原来的伙伴。角色选择包括原版角色和已加载的模组角色，第三方角色的自定义库存、动作或装备可能影响兼容性。

模组设置提供四种语言。简体和繁体中文支持自定义配音，英文和俄语使用角色原声。可以单独关闭伙伴语音。默认指令轮盘是 `Alt+R`，右键轮盘按钮可以替换指令。伙伴面板用 `Alt+鼠标右键` 在伙伴身上打开。两个界面也可以分别设置功能键或屏幕顶部按钮。

## 好感、领队与聊天

每位玩家都有自己的好感度。通常从 20 开始，陪伴、喂食和赠礼能提高好感，攻击伙伴会降低好感。跟随需要至少 25，工作需要**超过 50**。多人房间里，同一优先级下最后一个有效的跟随请求可以接任领队。好感达到 90 的请求优先。拿物品、改名、换角色和交换身体各有距离及权限要求。[权限细则](DEVELOPER.md#4-好感度领队与权限)

聊天时用伙伴**当前的名字**加上指令。比如「温蒂，种树」会让她用随身树种在她接到指令的位置周围种植。「温蒂，这是新基地」则以**发令玩家**脚下为中心。聊天和轮盘使用相同的权限。

轮盘里的「别钓」可以结束当前钓鱼任务。英文和俄文界面也可在轮盘目录中选择停止钓鱼。

伙伴主动询问时可以直接答。问起石果时可以说「敲吧」或「不敲」，问糖豆时可以说「吃吧」或「不要」。这些回答只在问题仍有效时生效。

## 交换身体后下线

交换后，玩家控制伙伴的角色，伙伴用玩家原来的角色继续活动。掉线后默认保留 **15 分钟真实时间**。在期限内用同一账号重连，可以接着玩。房主可在「换体离线保留时间」中选择 5、15、30 或 60 分钟。已经开始的倒计时会随世界保存。

到期后，伙伴在忙碌动作结束时归队，其他玩家可以再次交换。离线玩家以后回来，会自动领回由 AI 操作的那具身体。比如你用威尔逊换走温蒂，温蒂带回你下线时她身上的物品；你回来时拿到威尔逊在归队那一刻携带的东西。原版下线时掉到地上的物品留在地上。死亡状态也跟着身体保存。

去洞穴、返回地面或在月门选人期间都可以继续原有交换。两具身体分处不同分片时，超时交接需要两边服务器连通。

## 基地与行囊

设好基地后，伙伴会记住附近的锅、冰箱、盐盒和箱子。基地半径为 48 单位，设基地后仍可结伴出门。停止跟随时，她会在营地生活，有时会找一把空椅子坐坐。

- **装备。** 在玩家设置的基地，缺少武器或护甲时，伙伴会用随身和基地内可取用的材料补装。优先尝试猪皮头盔和火腿棒，其次是木甲和长矛。科技、工具和材料仍要满足原版要求。
- **吃饭。** 伙伴缺粮时会按角色饮食挑选采集目标。锅里的菜熟了，即使伙伴饥饿或受伤，也可以在安全时收菜。沃利没有可直接吃的随身食物时可以在低饱食度做饭；沃拓克斯饱食度低于 65% 且口袋里超过 10 个灵魂时，会优先吃魂。
- **天气。** 保温、防雨和降温都用实际装备。可在基地准备暖石；身上有寒冰护符时，伙伴会在炎热时戴上，降温后收起。
- **角色本领。** 喊「奶奶，读雨书」，维克巴顿会找随身、附近或基地书架里的雨书。她会下牛开架，读完把书留在架上。沃拓克斯能用灵魂治疗玩家，也会在安全时每缺至少 20 点生命放出一颗魂为自己回血。薇格弗德有材料时能制作和充能奔雷矛。其他角色的专用物品与能力见[角色章节](DEVELOPER.md#12-角色专属能力)。

## 战斗与救援

伙伴会协助当前领队，评估防具与敌人的攻击时机。血量和装备不足时会撤退。要她脱战追上你，可以再发一次「跟着我」。战斗中也可以喊「温蒂加油」，她有机会回你一句。

只要附近有可用的复活物品或角色能力，伙伴在跟随、待命、基地或独立活动中都可以救援 20 单位内的玩家。如果伙伴自己变鬼，会在公屏求助两次。带名字喊「去大门重生」可让她前往大门，单说「复活」或用轮盘则会寻找附近 16 单位内的复活点。

你变成鬼魂后，伙伴默认在附近守候。想让她继续同行，可以在聊天里带名字喊「跟着我」，或用轮盘的「跟随」。最低好感度仍是 25。你飘到她走不到的水面时，她会等你回到可通行的位置。

## 在营地下一盘棋

好感达到 20，打开伙伴面板，点信息框右下角的「游戏」。可以选伙伴对弈、邀请同一分片的玩家，或选自己执两方。邀请有效期为 45 秒。收起棋盘后对局继续，世界时间也照常流逝。

| 棋种 | 规则 |
| --- | --- |
| 五子棋 | 15×15，黑先，无禁手，同色连成五子或更多即胜 |
| 围棋 | 19×19，黑先，白贴 7.5 目，数子法。双方连续停一手或同意数子后可标记死子，双方确认后结算，有争议可恢复落子 |
| 中国象棋 | 红先，先选棋子再选落点。将死、困毙均判负，重复局面按简化长将规则处理 |

和伙伴下棋可以直接悔棋，和玩家对局需要对方同意。「历史对弈」按分片保存双方名字和结果。断线或换分片会结束当前对局，聊天和棋谱不存档。

## 本机助手与房间排错

日常玩法在游戏内即可使用。需要语音输入、模型对话或自然语言任务时，再到模组设置开启「AI大模型模式」。Windows 可双击根目录的 `StartVoice.vbs`，Linux 专服使用 `StartAssistantLinux.sh`。[安装与配对](../tools/companion_bridge/README.md)

开启洞穴的房间启动失败时，对照地上、洞穴及客户端日志。若看到 `CURL ERROR (28)` 和 `ValidateGameSessionTokenResponse Network Failure`，检查专服进程到 Klei 登录服务的连接。若新建世界反复提示 `PANIC: missing required prefab`，可用中型地图和默认生成设置另建测试世界。反馈时附上模组版本、服务器类型、角色、复现步骤以及完整 Lua 报错栈。[报告问题](https://github.com/Im-Chuyu/Journey-Together/issues)
