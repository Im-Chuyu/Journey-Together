# 一路同行 · Journey Together

[English](README.en.md) · [开发文档](DEVELOPER.md) · [翻译贡献](CONTRIBUTING.md)

**一路同行**是《饥荒联机版》（Don't Starve Together）的 AI 伙伴模组。伙伴使用真实角色实体，保留原版角色能力、饮食限制和装备系统，通过聊天、指令轮盘和物品面板与玩家互动。

伙伴可以跟随协战，也可以独立建立基地、管理物资和维持生存。好感度按玩家分别记录，多人房间中的跟随与指令权限由服务端统一判断。

## 主要功能

| 系统 | 能力 |
| --- | --- |
| 伙伴互动 | 好感度、跟随与待命、改名、角色与皮肤选择、实体交换 |
| 工作与基地 | 采集、砍树、挖矿、农业、整理、搬运，以及独立基地建设 |
| 生存与补给 | 进食、限定状态下烹饪、照明、温度与防雨换装、物资补充 |
| 战斗与救援 | 协战、按攻击时机躲避、护甲选择、掉落武器取回、主动复活附近玩家 |
| 角色能力 | 沃拓克斯灵魂管理、维克巴顿读书与书架记忆、薇格弗德奔雷矛等专属行为 |
| 多人交互 | 服务端 AI、聊天与轮盘指令、物品面板、分片迁移与保存恢复 |
| 娱乐 | 五子棋伙伴对战、玩家邀请对战、自弈测试，以及跟随伙伴的下棋陪坐 |
| 语言与语音 | 简体中文、繁体中文、英文、俄语，以及中文自定义语音 |

## 安装与启用

本模组需要安装在 **服务器和所有客户端**，不属于仅客户端模组。

1. 使用仓库源码时，将模组目录放入游戏的 `mods/` 目录，确保 `modmain.lua` 和 `modinfo.lua` 位于该模组目录的根部。
2. 在世界的服务器模组列表中启用“一路同行”。专用服务器需在对应分片的模组配置中启用，并让所有客户端使用一致版本。
3. 按需要设置伙伴语言、语音和快捷键，再进入世界。首次创建的伙伴默认是温蒂，生成位置优先在绚丽之门等世界入口附近；已有伙伴会从存档恢复。

角色目录支持原版角色和已加载的模组角色；具体模组角色及其他改变库存、动作或状态图的模组，需要分别验证兼容性。

## 快速上手

### 常用操作

| 操作 | 默认方式 |
| --- | --- |
| 打开指令轮盘 | `Alt+R` |
| 自定义轮盘位置 | 右键轮盘按钮，从分页目录选择指令 |
| 打开伙伴面板 | 对伙伴按 `Alt+鼠标右键` |
| 发送聊天指令 | 在同一条聊天信息中包含伙伴当前名字和指令关键词 |

轮盘的 Alt 快捷键可设置为 `Alt+A` 至 `Alt+Z`。轮盘和面板还可分别设置额外的 F1–F12 快捷键，并启用屏幕顶部按钮。

例如，假设伙伴当前名为“小薇”，可以发送：

- `小薇，跟着我`：请求跟随。
- `小薇，在这等我`：原地待命。
- `小薇，这是新基地`：设置当前基地。
- `小薇，砍树`：请求工作，仍需满足权限和工具等条件。
- `小薇，种树`：也可说“种下去／种吧”，用随身树种在伙伴发令位置横纵各延伸 10 单位的方形内种树。
- `小薇，准备奔雷矛`：薇格弗德专属制作与充能指令。
- `小薇，去大门重生`：鬼魂伙伴前往大门复活；也可说“绚丽之门复活”“传送门重生”。地点词与复活词分开匹配，需同时出现；不带地点词的“复活／重生”等指令与轮盘“复活”一样，寻找附近 16 单位内的复活点。

关键词随所选伙伴语言变化。聊天和轮盘共用指令权限，角色专属指令仅由对应角色执行。

伙伴询问后可直接回复，不必带名字：石果回复“敲吧／不敲”，糖豆回复“吃吧／不要”，拾取许可回复“可以”。这些是待回答问题的聊天回复，不是指令，也不出现在轮盘；没有对应问题或问题过期时不会触发。石果同意后先丢下整堆，再按普通挖矿方式连续挥镐，危险和其他高优先级行为仍可中断。

### 好感度与多人权限

每位玩家的好感度独立计算，通常初始为 20。喂食、赠送物品和陪伴可以提高好感度，攻击伙伴会降低好感度。

- 请求跟随需要至少 25 好感度；劳动指令要求好感度严格大于 50。
- 同一优先层级中，最新有效跟随请求可以接替当前领队。例如 A/B 好感度为 30/50 时，B 可以接替 A。
- 好感度达到 90 的有效跟随请求具有更高优先级；伙伴没有领队时，旧请求不会一直锁住伙伴。
- 拿取物品、改名、换角色及实体交换有各自的距离、状态和权限要求。

当前源码另有指定用户固定满好感的特例，定位及规则见[开发文档的权限说明](DEVELOPER.md#4-好感度领队与权限)。

## 主要行为规则

伙伴战斗时，可在公屏发送“伙伴名字＋鼓舞语”，例如“温蒂加油”“温蒂你能行”“温蒂我相信你”。伙伴会随机回应感谢或鼓劲台词，不打断战斗，不要求跟随或消耗好感；同类回应至少间隔 6 秒。空手或只有低伤害工具时也会装备随身可用护甲。

伙伴面板的信息框右下角有“游戏”按钮，好感度至少 20 即可使用。选择“五子棋”或“围棋”后，可与伙伴对战，或从当前世界（同分片）的在线玩家中选择对手；选择自己直接开局，轮流执黑白测试。双方随机分配黑白，黑方先手。受邀者点击伙伴 HUD 按钮下方的提示，再选择应战或拒绝。邀请 45 秒过期。

棋盘不会因受击或死亡自动关闭；“收起”保留对局，“退出对局”确认后结束并离开。左侧可申请黑子先手：对手同意后清空棋盘重开，伙伴会自动同意，申请 30 秒过期。角色名字旁显示当前头部皮肤头像，下方聊天一次显示五条，可上下滚动查看最近 40 条；支持快捷语和当前游戏完整表情目录，所有消息仅在对局内显示。伙伴在开局、对弈中以及玩家获胜/失败时有随机台词；玩家互相对战时，会为自己跟随的玩家加油。娱乐按钮、任务与台词均覆盖简体中文、繁体中文、英文、俄文。

世界照常运行，进行中的棋盘不恢复；断线、换分片或身体移除会结束对局。棋盘左上方“历史对弈”可查看当前世界分片保存的所有已结束对局，包含双方名字、胜负/和棋/中止及游戏类型；结果分页存储，重启后仍可查看，不保存聊天和棋谱。记录独立于世界快照，回档不会回滚已经保存的历史；地上与洞穴分别记录，旧版本未记录的对局无法补回。

五子棋为 15×15、无禁手，连续五子或以上获胜。围棋为 19×19，白贴 7.5 目，采用子空皆地计分、禁止自杀和全局同形再现。连续两次“停一手”或双方同意“申请数子”进入数子；点击棋子标记/取消整组死子，任意标记变化会取消双方之前的确认，双方均确认后结算。有异议可“恢复落子”；“求和”需对方同意，申请 30 秒过期，继续落子使申请失效。伙伴对弈可以直接悔棋，回退玩家和伙伴最近一轮；玩家之间需要对手同意悔棋，申请 30 秒过期。自弈需分别确认两次；伙伴是基础棋力，接受数子和求和，并同意玩家指定的死子，不自动裁定复杂死活。同时接壤双方棋子的空地不判给任何一方。

聊天保持五条可见消息并压缩行距，长消息悬停查看全文，给棋盘留出更大空间。围棋伙伴使用固定小范围的有限预判，优先提子、救一气棋组、连接、断点和做眼，再考虑对手的有限应手；只在轮到伙伴落子时计算，搜索树在该步结束后释放。娱乐不新增世界扫描或轮询同步；操作时才校验、定向同步或读写历史，伙伴落子与邀请过期等使用一次性任务。只有伙伴正跟随对局玩家时才会靠近并持续 `/sit`；生存、战斗和工作可打断，结束后再回来坐下。

| 范围 | 当前行为 |
| --- | --- |
| 设置基地 | 以玩家发令时的当前位置为中心，半径 32 单位；保留锅、科技站、盐盒、冰箱、箱子等设施的发现与记录，中心不向设施偏移。指令不自动取消跟随 |
| 战斗躲避 | 根据敌人攻击动画与危险时机撤退或侧移；危险躲避可在普通攻击命中前将其打断。进食、救援和施法等忙碌动作仍受保护 |
| 环境撤离 | 受到火焰、孢子云等区域伤害时优先离开危险区，再继续战斗；冰眼只避开直接压低体温的内圈（原版半径 3.5），不会把可由加热抵消的外圈降温范围（半径 35）整片封锁。其他活动温度源按实际危险范围撤离。失败会换方向重试，离开后避开已记录的危险区。识别由受伤触发，不做持续全局扫描 |
| 上下文台词 | 只有天数负差值在 -2 至 -1 或 -5 至 -3 时触发对应回档台词；季节变化和跟随领队附近的降雨也会触发台词。天数基准独立保存，雪天不当作下雨，持续降雨台词间隔 120 秒 |
| 协战标记 | 领队每次攻击刷新该目标的协战标记，最后一次攻击后保留 16 秒；仍需满足原有战斗安全和距离条件 |
| 多人协战 | 只协助当前跟随的领队，不因其他玩家交战而参战；未跟随时只按自身威胁和战斗规则行动 |
| 上下船跟随 | 以领队当前位置为目标，由原版选择可达跳船点；不补走旧上船路线。实际上船后先朝玩家方向在船面移动一次，最多 4 单位，完成前不被下船跟随覆盖，受阻超时退出。下船后恢复地面寻路，重新跟随会清理旧失败路线；不做独立周期平台观察 |
| 跟随脱战 | 普通跟随时离领队超过 32 单位就停战追赶；再次下达“跟随”会脱离当前战斗，5 秒内不与刚才的目标交战，到期后按原有规则重新判断。聊天和轮盘一致，危险区域撤离及忙碌动作仍受保护 |
| 战斗装备 | 按当前攻击的有效减伤优先选护甲；减伤相同时综合当前温度、防雨、移速收益与耐久。多功能装备保留护甲资格；启迪之冠仅在头部没有可用护甲时作为战斗回退，日常仍优先佩戴 |
| 装备不足撤退 | 血量低于 80%、随身没有可用护甲且可用手部装备攻击力都低于 25 时停止交战并远离威胁，不因早期主动迎战或协战而空手硬拼。随身库存、背包和已穿戴的装备都会计入 |
| 基地补装 | 玩家设置新基地后，伙伴在基地内空闲且缺少武器或护甲时，会用基地内地面、可访问箱子及随身材料补齐装备；优先猪皮头盔＋火腿棒，再尝试木甲＋长矛。整套都凑不齐时仍会制作材料足够的单件，可自行搓绳。已有装备不重复制作，都无法制作时等待 4 分钟再查；仍需满足原版科技要求，生存、战斗和明确指令优先 |
| 战斗武器 | 火把不作为武器候选；伙伴手持火把时拒绝用它攻击，并优先卸回库存。春秋沿用原温度逻辑；夏冬仅在高于 60 或低于 5 的极端温度下切换隔热/保暖装备 |
| 防雨装备 | 按装备与角色自身防雨计算，同槽备用装备不重复相加；在玩家设置的基地内，总可用防雨低于 80% 时会寻找材料制作雨伞，20% 防雨的猪皮头盔不会阻止造伞，达到 80% 则不造。雨伞与防身补装同优先级，失败冷却各自 4 分钟。实际穿戴达到 100% 后不再额外装备纯雨具，已有冗余按空闲换装规则收起；仍用于保暖、隔热等用途的多功能装备会保留 |
| 装备维护 | 耐久不高于 15% 时，用随身材料执行原版缝补或锻造修理，支持眼球伞、暖石、暗影伞及虚空装备等。骨甲等可用噩梦燃料的装备低于 10% 时开始补充，超过 90% 停止；缺材料不执行，库存/耐久无变化不重复检查 |
| 设施与资源发现 | 优先使用已有记录，无目标且没有相关变化时停止重复搜索；设施、资源、库存或搜索区域变化后重新发现。使用共享事件通知，避免给全世界实体逐个挂监听；缓存不阻止已移除对象回收，搜索范围和目标排序保持原规则。读档重建临时缓存 |
| 武器掉落 | 优先取回附近 8 格内实际掉落的装备；有超时与重试间隔，已被玩家或其他实体拿走时停止恢复 |
| 伙伴复活 | 鬼魂状态下，聊天或轮盘“复活”指令会寻找附近 16 单位内的可用作祟复活点。变鬼和复活时清理旧行为，复活动画结束后恢复有效的跟随或待命关系，支持旺达二次机会表 |
| 种树指令 | 以发令时伙伴的位置为固定中心，在 20×20 方形内按建家林区间距均匀种树，不留中央通道，数量随边长和间距计算；当前空地可容纳 64 个位置，材料不足时种到用完。使用随身松果、桦栗果或多枝树种子，不清场、伐木、取箱子或移动原基地林区，沿用工作指令权限 |
| 迎战范围 | 显示天数小于 500 时主动迎战仇恨伙伴或附近玩家的生物；从第 500 天起恢复原有战斗评估规则。仅仇恨玩家且未触发参战时继续原行为，不因此逃跑；逃跑针对伙伴自身受到的威胁及装备不足时正在退出的战斗。亮茄本体仅在虚弱时可攻击 |
| 主动救援 | 跟随、待命、基地闲逛和独立活动时均可救援附近 20 格内的玩家，需要可用的复活物品或角色能力 |
| 自主烹饪 | 各活动模式均可烹饪；只主动烤制食用扣血或新鲜度低于 20% 的原料，单纯扣理智不烤。保留从允许使用的冰箱、盐盒、箱子取料做锅料理的能力 |
| 料理选择 | 按当前三维缺口选择配方：低生命优先回血，低理智优先理智恢复，低饱食度优先高饱食料理；三维都高时优先高饱食收益，避免固定偏爱肉汤 |
| 糖豆 | 糖豆（`jellybean`）不自主进入普通进食选择；生命低于 20% 且没有足够回血食物时，单次查找身上、附近容器和地面的糖豆，询问跟随玩家后最多吃一次，扫描冷却 4 分钟 |
| 食物保护 | 自主进食在选食及真正吃下前检查当前生命值，拒绝预计致死的一口，覆盖随身食物与容器取食。不吃蜂王浆、曼德拉草和生高鸟蛋；不主动吃眼球和犀牛角，玩家主动喂食这两件物品仍按原版角色饮食规则处理 |
| 普通治疗 | 旺达及带有年龄组件、年龄血量标签或原版不可治疗标记的角色，不作为丢魂/喂食回血目标；仍可因饥饿接受食物 |
| 入锅限制 | 蜂王浆、曼德拉草和蜜脾（`honeycomb`）不入锅；新鲜度不低于 50% 的肉干不入锅；新鲜大肉最多两份，第三份只有低于 20% 新鲜度时才可作为需要消耗的过期大肉 |
| 后期物资 | 从显示第 151 天起停止通用基础物资囤积，仅低优先级维持 10 草和 10 树枝；明确任务和角色专属物资另行处理 |

躲避效果取决于敌人攻击时机、可移动地形和当前角色状态，并不保证完全避伤。详细阈值、例外和模块调用关系见[开发文档](DEVELOPER.md)。

### 角色专属行为示例

- **沃拓克斯**：在物品栏与随身灵魂罐之间调配灵魂，目标为物品栏保留 18 个；不把灵魂转入背包。物品栏灵魂超过 10 个且饥饿时优先吃灵魂。
- **沃拓克斯治疗玩家**：周围 10 单位内玩家血量变化时检查，另每 30 秒做一次同范围兜底检查。低于 80% 时沿用走近并丢单颗魂的治疗流程，达到 80% 停止；不反复轮询全服玩家血量。
- **维克巴顿**：设置基地时记忆书架位置，读书和放书可前往远处已记录的书架。读书时没有可用书，每条指令最多补查一次基地；在基地外或仍没找到时，补查伙伴身边 20 单位内的书架。基地外临时记录仅用于本次读书，不写入存档；没有周期扫描。
- **薇格弗德**：保留只吃肉的限制，优先进食肉干。使用奔雷矛时每四次普通攻击接一次闪电冲刺；低耐久时转为仅冲刺，避免冲刺攻击会因电击燃烧的生物。
- **旺达与沃拓克斯**：具备对应物品或材料时，使用角色专属能力救援玩家。

薇格弗德收到“奔雷矛”指令后，只使用随身材料制作至多一柄，再尝试用一份约束静电充能随身或手持的未充能矛，优先手持武器。已有武器无需先制作；不自动采集或取用箱子材料。手持武器充能需一个可用空位。她仅在随身没有普通或充能奔雷矛时，每五个游戏日向当前领队询问武器或材料，并接受 30 秒内的拒绝回复；收到矛后停止该询问及待回复互动。

## 语言与语音

可在模组设置中选择简体中文、繁体中文、英文或俄语。初始语言随游戏语言选择，未匹配时使用英文；缺失语言资源有中文回退。

简体中文和繁体中文可播放自定义伙伴语音，英文和俄语沿用角色原生声音。关闭“伙伴语音”后不会注册自定义 FMOD 声音银行，适合与大型音频模组一起使用。

在模组根目录使用 Lua 5.1 对受影响的文件执行 `luac -p <文件>`，并运行相关回归；小改动不要求全量检查。完整命令和按改动范围选择检查的规则见[开发文档第 18 节](DEVELOPER.md#18-扩展步骤排错与验证)。桩测试之外，涉及网络、存档或角色交换的改动还需在游戏中验证。
