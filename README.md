<h1 align="center">一路同行 · Journey Together</h1>

第一次走进永恒领域，可以去绚丽之门附近找找温蒂。给她带点吃的，等她愿意跟你走，就能结伴出门。路上她会躲避攻击、捡回掉落的武器；回到营地，你可以请她砍树、种树，或坐下来陪她下一盘棋。

《一路同行》给《饥荒联机版》的世界加了一位能独立生活的伙伴。换个角色，同行的方式也会变。维克巴顿记得家里的书架，沃拓克斯会用灵魂给自己和受伤的玩家回血。跟随、劳动和角色能力都随模组提供，无需配置模型或运行助手。

## 加入世界

1. 在 [Steam 创意工坊](https://steamcommunity.com/sharedfiles/filedetails/?id=3802676080) 订阅模组，在世界的**服务器模组**列表启用「一路同行」。
2. 主机和每位玩家使用同一版本。专服开了洞穴时，地上和洞穴两个分片都要启用。
3. 进世界后，在伙伴身上按 **Alt + 鼠标右键**打开面板。初次见面时好感度通常是 20，达到 **25** 就可以邀请她跟随。

| 想做什么 | 游戏里怎么做 |
| --- | --- |
| 邀请同行 | 按 `Alt+R` 打开指令轮盘，或在聊天里喊「温蒂，跟着我」。变成鬼魂后也可重新发令 |
| 让她在原地等 | 喊「温蒂，在这等我」。改过名后，用她现在的名字 |
| 记住营地 | 站在想设为基地中心的位置，喊「温蒂，这是新基地」 |
| 一起干活 | 好感度超过 **50** 后，给她合适的工具，再喊「温蒂，砍树」 |

模组支持简体中文、繁体中文、英语和俄语。指令词随伙伴语言切换，快捷键可以在模组设置里调整。

交换身体后掉线，默认有 15 分钟可以重连继续。超时后伙伴归队，你的身体和物品会保留到下次上线。[换体与离线规则](docs/player-guide.md#交换身体后下线)
