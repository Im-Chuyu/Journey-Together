# 本机动作与语音助手

双击模组根目录 **StartVoice.vbs**（无控制台；`StartVoice.cmd`保留为兼容入口，CMD随即退出），或运行：

```powershell
python -B -m tools.companion_bridge
```

## DeepSeek API：填写 Key 即可启动

模组根目录的 `AssistantAPI.json` 是用户本机配置；若不存在，第一次启动助手会自动生成，也可复制 `AssistantAPI.example.json` 并改名。只需将 `api_key` 的空字符串填为自己的 DeepSeek API Key，保存后双击 `StartVoice.vbs`，即可进入 API 模式。无须加载网页扩展或打开模型网页。模组配置仍须开启“AI大模型模式”，游戏六位配对码与助手一致（默认321151）。助手文字/语音可以直接对话，游戏公屏需要带伙伴名字。

最少配置（省略项使用默认值）：

```json
{
  "api_key": "在这里填写自己的DeepSeek密钥"
}
```

首次准备 Python/Tk 仍由启动器处理，API模块使用Python标准库，无需额外安装SDK。文本互动不需要语音模型；语音按原设置另行准备。

| 配置项 | 默认值 | 含义 |
| --- | --- | --- |
| `provider` | `auto` | 填Key自动用API，未填保留网页模式；`deepseek-api`强制API（缺Key报错），`web`强制网页 |
| `api_key` | 空 | 自己的Key；为空时也可读取环境变量`DEEPSEEK_API_KEY` |
| `model` | `deepseek-flash` | 可改为官方支持的模型ID，如`deepseek-v4-pro` |
| `thinking` | `true` | 启用思考模式 |
| `reasoning_effort` | `low` | `low`、`high`或`max`，仅思考模式使用 |
| `max_tokens` | `8192` | 每次回复（含推理）的输出上限，允许512～32768；出现截断可提高 |
| `timeout_seconds` | `120` | 单次网络操作超时，允许10～300秒 |
| `retries` | `1` | 429及指定临时服务错误的自动重试次数，允许0～2；普通网络超时不自动重发 |
| `ambient_enabled` | `false` | 是否允许API主动闲聊；默认关闭以免产生后台调用费用 |

也可在助手主窗口点击“大模型设置”（或“助手设置 → 大模型设置”），直接配置连接方式、Key、模型、思考开关/等级、输出上限、超时、重试和主动闲聊。模型下拉提供常用ID，也允许填写自定义ID；Key默认遮挡，关闭思考时等级选项禁用。保存会校验参数并写入同一个 `AssistantAPI.json`，环境变量中的Key不会被自动写回文件。

保存后重启助手生效，当前任务继续使用原参数。API模式窗口显示所选模型、请求次数及累计输入/输出Token（本次启动）；Token统计以收到的API响应为准，不含无法收到响应的计费，实际费用以DeepSeek账单为准。Key错误、余额不足、限流、连接失败和输出截断会明确提示，不回退演示。错误正文、Key及模型思考内容不写日志、不经游戏网络广播。新指令/停止/退出会取消当前请求并丢弃迟到结果；取消不能保证远端已停止计费。

原生工具只返回决定，动作仍在游戏主模拟端按原权限执行。每轮一个顶层工具，连续工作走`execute_sequence`，实际回执通过tool消息续接，思考字段在同一任务内保留；新玩家任务重新建立API上下文。参数校验失败不执行该次调用，会将接口/字段路径和Schema错误反馈模型，最多纠正一次并续接原任务；仍失败则显示具体位置。纠错可能额外产生一次API调用，其Token计入窗口用量，不重跑先前成功步骤。未授权、截断或一次返回多个工具仍直接拒绝。

本机 `AssistantAPI.json` 为明文个人配置，Git和发布导出均排除；`export_workshop.py`重新生成空的实际配置及示例，即使开发者编辑过示例也不复制Key。上传时使用导出目录；手动复制发布也须将Key清空。其他用户填写自己的Key与余额。官方接口/模型说明：[首次调用](https://api-docs.deepseek.com/zh-cn/)、[工具调用](https://api-docs.deepseek.com/zh-cn/guides/tool_calls/)、[思考模式](https://api-docs.deepseek.com/zh-cn/guides/thinking_mode/)。本次以模拟API与游戏边界测试验证，未使用真实Key调用或验证真实游戏端到端。

## 网页模式及原有功能

Windows 64位。启动器优先使用已有 Python 3.10+ 与 Tkinter；没有时首次联网下载并安装到模组目录，无需手动安装 Python。模组只附脚本，不附 Python、语音依赖或模型。未填写API Key时使用通用网页桥接（DeepSeek/豆包）（试验接入，当前Chrome基础问答回传已实测通过）。`--voice-check` 检查识别器，`--speech-language` 选择已安装语言。

首次在 Chrome/Edge 加载 `browser_extension` 后，**F5 刷新已有 DeepSeek 页面**，将助手“复制网页连接码”粘贴到扩展，直到弹窗显示网页脚本和本机助手均已连通。开启AI大模型模式，进入世界自动连接，无需先跟随或靠近；本地控制台配对命令保留。F9识别一段话，可在助手设置改为F1～F12；“开启持续语音”持续接收多句话，再次点击停止。仅游戏公屏须带伙伴名字，助手文字/语音无需称呼。房间只需一台已连接的助手，所有玩家可聊天，地面/洞穴消息有服务端转发；跟随时仅领队可安排工作，独立时人人可安排基础工作。断开恢复原公屏逻辑。

在模组配置开启“AI大模型模式”后始终自动连接；关闭时不启用模型接口及连接任务。默认六位码321151，在助手“助手设置”可自定义六位码及网页长码；都保存在 `tools/companion_bridge/.local/settings.json`，重启不变。扩展保存配对，重新打开网页或助手后自动重连；原页有效时保留，多页不明确时切到要用的页面，游戏按5秒递增间隔重连，连续30次失败停止，下次进世界重置。开启连接不会停止现有工作。游戏/模型任务双向安全接替，角色语气及60～120秒随机主动闲聊见完整说明。

2026-11-02已由玩家在真实Chrome验证库存问答自动回传，游戏内显示伙伴回复；复杂动作、远程客户端和长期后台稳定性仍待实测。网页可能需要手动登录、验证或发送，扩展不绕过网站限制。`--provider demo` 单独选择离线演示，网页模式不会偷偷回退演示。

`--adapter <本地py文件>` 加载用户自行选择的模型适配器，契约见 `provider.example.py`。`--headless` 仅启动回环服务，控制台会给本机自动化使用的 client token；不提供录音窗口。

### Linux 云服公屏模式

在专服所在的 Linux 环境安装 Python 3.10+。在该模组根目录的 `AssistantAPI.json` 填写 DeepSeek API Key，并在专服模组配置中开启「AI 大模型模式」。运行 `sh ./StartAssistantLinux.sh` 启动无界面 API 助手。助手在云服监听 `127.0.0.1:18766`，可传 `--pair-code 123456` 设置与游戏配置一致的六位配对码。默认配对码为 `321151`。

有活动伙伴和在线玩家时，专服会从伙伴所在分片自动配对，无需先跟随。配对成功后，玩家在公屏喊伙伴名字即可交互。助手与专服需要能访问同一个回环地址。助手尚未启动或会话断开时专服会重试；配对码不一致时停止当前分片的自动配对。对齐配对码后重启该分片，或在伙伴所在分片的专服控制台用实际六位码执行 `c_myfriend_ai("start", "321151")` 恢复配对。

跟随使用原版模式，动作完成后恢复正常活动，无须取消跟随再拾取。新增 `interact` 支持坐椅子、开关和激活组件；观察会公布支持能力。网页后台等待有 120 秒宽限，扩展定时唤醒真实页面；“诊断日志”可查看不含聊天正文/连接码的有界元数据日志。

完整使用、35 个接口、控制权、返回值、模型适配和验证边界见根目录 [BODY_API.md](../../BODY_API.md)。

批量捡掉落物用 `pickup_many`，批量采摘/工作用 `work_many`，游戏连续执行后统一返回实际数量和失败项；`craft(count)`本来就支持连续制作整批。基础动作和紧急生存的原有交接规则保留。

世界接口含存档、回档、暂停/恢复、踢人和原生黑名单。取消管理员授权；每项操作都必须由伙伴先问原因、玩家下一条回答后再由模型评估，合理才执行。详见 [BODY_API.md](../../BODY_API.md)。

当前35个接口支持实时配方查询、角色能力目录/原脚本调用和独立锅收成；连续实物步骤间自动保留计划控制，纯聊天不占用。首次更新需重新进入世界并重启助手以同步接口，本次还需重新加载浏览器扩展并刷新模型页。

网页扩展现支持DeepSeek与豆包，在助手“打开模型网页”菜单选站点，并在该页扩展中“连接当前标签页”。自动新对话默认开启，只在可见会话上限提示出现时触发，没有固定轮数限制；保留连接码与同一待完成请求，完整状态和回执随新页请求携带。站点切换需主动连接，自动恢复不跨站点。更新需重启助手、重载扩展并F5刷新页面、允许豆包站点权限；旧deepseek-web启动参数兼容，web为新通用入口。豆包真实网页联调仍待用户验证。

补充：新增query_actions/perform_action，可组合身上/手部使用、指向实体/坐标使用、建筑右键及GIVE。传送魔杖和留声机给予已有原生隔离验证；单个work目标默认做到完成。助手文字/语音无需伙伴名，公屏仍需。世界操作取消管理员授权，存档/回档/暂停及新增踢人/黑名单均须先问原因、收到同一玩家后续回答，由模型判断合理后执行；不允许首次直接执行。

新增通用query_batch与execute_sequence：一次合并多项只读查询，一次连续执行已确定步骤；失败停在该步并返回实际进度，可只对剩余部分降级单步。普通动作自行接近目标，减少无意义的先移动再操作。支持种植/部署/挖铺地皮的原生动作，drop新增指定位置。详情见BODY_API.md。


任务准备与恢复：`query_recipe` 现在合并库存缺额、地面/容器取料来源、科技站和建筑选址。`query_sites` 支持建筑配方或已携带部署道具；原生合法点仍需模型判断用途与布局。建筑要求每步一个明确坐标，多座用序列；位置失败只补做剩余步骤。提示词重组身份、基础玩法、组合规划和输出规则，快照补潮湿/日内时间/地面物品/boss。网页修复增加新对话入口变体及公开首页回退，豆包发送兼容更多富文本/控件并报告发送未确认。须重启助手、重载扩展和刷新标签页；真实网页及复杂游戏任务仍待实测，详见 BODY_API.md。


语音更新：助手设置可选“Whisper 离线识别”或“Windows 系统识别”。首次点击“安装/准备离线识别”，联网安装独立运行库及约461MiB的small多语言模型，再选Whisper并保存。安装日志在 `tools/companion_bridge/.local/logs/voice-setup.log`；模型和运行库仅存本机 `tools/companion_bridge/.local/`，不提交、不随模组发布。准备好后识别完全本地运行，使用CPU int8、4线程；未配置CUDA。首次载入有延迟，持续识别复用同一模型进程。录音仅在快捷键/识别按钮/持续语音开启后开始，关闭或退出会结束进程。响度、噪声、麦克风距离仍会影响准确率，建议先关闭自动发送检查识别文字。

朗读可选本机SAPI音色，调整语速(-10～10)与音量(0～100)，设置中可试听。列表以当前已安装且System.Speech可访问的音色为准；更多音色需自行安装兼容引擎，不包含参考音频克隆。配置保存到现有 `tools/companion_bridge/.local/settings.json`，修改配对码不会丢失语音偏好。

启动器改用pythonw独立启动，关闭已退出的兼容CMD不会结束新启动的助手；关闭助手主窗口会正常关闭服务和语音。旧版本已经打开的CMD可能仍关联旧进程，首次更新建议先从助手窗口正常退出，再双击VBS。启动失败会弹窗并记录 `tools/companion_bridge/.local/logs/startup-error.log`；`start.ps1 -CheckOnly`仅检查启动环境，不打开助手。

快捷键现在为按住录音、松开识别：F1～F11在专用线程注册并直接处理WM_HOTKEY，通过按键状态检测松开；F12在同一专用线程用低级钩子收集按下/松开。Tk只读取事件，不再与系统快捷键争用消息。Windows和Whisper均有独立hold识别路径；Whisper先录音后加载模型转写，按住时短暂停顿不提前结束，最长约20秒。按钮仍可点按识别或手动开启持续语音。麦克风只在明确操作后启用，退出时清理线程和进程。已移除识别术语输入、预置提示和旧配置传递；保存配置会清除旧asr_prompt。更新后先正常退出旧助手再重新启动，释放原快捷键注册。真实游戏全屏/窗口下的物理按键和麦克风仍需实测。


### 创意工坊发布与首次使用

玩家双击 `StartVoice.vbs`。没有 Python/Tk 时，启动器依次尝试 Python 官网、阿里云和华为云镜像。下载错误、25 秒无进度或 SHA-256 不符会自动切换下载源。只有匹配固定 SHA-256 的完整安装包才会执行，安装不修改 PATH。如果所有来源均失败，可在其他网络下载同版本的 64 位完整安装包，放到弹窗指定的 `.local/downloads/` 文件路径后重试。主窗口不等待语音模型下载，文字聊天可先使用。语音从“助手设置 → 安装/准备离线识别”安装，失败后可再次点击；首次约需下载461MiB模型及依赖。Windows系统识别仍取决于本机语言组件。

启动器以自己所在的模组目录为基准。Python 下载包、自动安装的 Python、语音运行库、模型及其下载缓存、配对设置和日志在 `tools/companion_bridge/.local/`，API 配置 `AssistantAPI.json` 在模组根目录。不同 Steam 库或文件夹名称会使用各自的路径。搬动已配置的目录后，若离线识别启动失败，在助手设置里重新准备语音以更新虚拟环境的 Python 路径。开发测试可设置 `MY_FRIEND_ASSISTANT_DATA_DIR` 隔离数据。

退出助手再删除模组目录即可清理这些本地文件。自动安装使用 Python 官方 Windows 安装器，系统可能保留安装注册项及维护缓存。若要一并清理，可先从 Windows 的“已安装的应用”卸载这次自动安装的 Python，再删除模组目录。电脑上原有、仅被助手复用的 Python 属于独立安装。

**上传前不要直接选择带旧 `.local` 缓存的开发目录。** `.gitignore` 仅用于Git，发布流程应明确排除本机文件。在仓库根目录运行 `python -B tools/companion_bridge/export_workshop.py`，会把当前工作区文件（含尚未提交的修改）复制到新的 `tests/.local/workshop-upload-时间/`，排除 README、`.local`、tests、Git目录、日志和Python缓存。检查导出目录后将它选为上传目录；脚本不上传、不改版本。原有网页扩展原样保留，安装教程由作者另行提供。


组合任务协议更新：助手在同一任务中回传简短plan笔记和剩余决策预算，帮助模型固定旧包/新包/收件人及剩余步骤；不自动执行笔记。料理可显式选定四格材料并查询总缺额，背包观察说明不可存储，工作回执带实际产物。须重启助手、重新进世界、重载扩展并刷新页面；详见BODY_API.md末节。


参数错误排查：诊断日志新增api_tool_rejected，包含category/path/repair而不记参数值、聊天正文、完整请求或思考。旧版本日志未记录被拒绝字段，无法据旧错误反推模型多传了什么；升级后须重启助手。采摘植株应按nearby观察，items只查地面物品。


扫描与地点状态更新：snapshot包含base/home/location，分别表示已记录基地、驻留点、脚下地皮和当前地图区域；没有记录不等于在野外，人工地皮也不证明区域。容器结果优先保留身份/位置，并用next_offset续查后页；contents_limited须定向补查，不能把截断当没有冰箱。需重启助手、重新进入世界。完整契约见BODY_API.md末节。
